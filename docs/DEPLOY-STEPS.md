# DEPLOY-STEPS — постоянная ссылка на Railway (от тебя — 10 кликов)

> GitHub-репозиторий уже создан и залит: **https://github.com/nafiks/mealmate**
> Осталось только «включить» его на Railway. Кодов и терминала не нужно — всё в браузере.

## Что ты делаешь (один раз, ~10 минут)

1. Открой **https://railway.app** → кнопка **Login with GitHub** → нажми **Authorize**.
   (Первый заход предложит создать workspace/team — соглашайся на предложенное.)
2. Нажми **New Project** → выбери **Deploy from GitHub repo** → в списке выбери
   **nafiks/mealmate** (при первом запросе нажми Configure GitHub App → All repositories
   → Install, чтобы Railway увидел репозиторий).
3. Начнётся первая сборка (5–7 минут). Пока она идёт, настрой два пункта:
4. **Переменная для базы данных**: открой карточку сервиса → вкладка **Variables** →
   кнопка **+ New Variable** → имя `MEALMATE_DB`, значение `/data/mealmate.db` → Add.
5. **Постоянный диск**: вкладка **Settings** → раздел **Volumes** → **+ New Volume** →
   Mount path: `/data` → Add. (Без этого рецепты сбрасываются при каждом рестарте.)
6. **Ссылка**: вкладка **Settings** → раздел **Networking** → **Generate Domain** →
   Railway выдаёт адрес вида `mealmate-production-a1b2.up.railway.app`.
7. Открой его — сайт работает **24/7 независимо от твоего ПК**. Эту ссылку
   отправляй команде и преподавателю.

## Стоимость

Railway даёт стартовый бонус (~$5) — демо проекта на такой нагрузке живёт на нём
неделями. Дальше тариф Hobby ~$5/мес, если захочешь держать сайт постоянно.

## Как обновлять сайт потом

1. Поменял файлы локально → открой PowerShell в папке проекта (адресная строка →
   `powershell` → Enter) и набери:
   ```
   git add -A
   git commit -m "мои изменения"
   git push
   ```
2. Railway сам заметит новый коммит и пересоберёт сайт (2–3 минуты).

## Если что-то пошло не так

| Симптом | Где смотреть / что делать |
|---|---|
| Сборка упала | Railway → сервис → **Deployments** → клик на красный деплой → View Logs. Чаще всего: на GitHub не хватает папок client/server — проверь репозиторий |
| Сайт открывается, но рецепты пропадают после рестарта | Не подключён Volume (пункт 5) |
| «Application failed to respond» | Подожди 2 минуты — первый старт медленный; проверь переменную MEALMATE_DB |
| Railway просит оплату | Стартовый бонус закончился — тариф Hobby $5/мес, либо используй ссылку-туннель (share-link.bat) |
