### Арсен — Frontend (клиент/, src/)
- **Дизайн-система** `client/src/styles/global.css`: палитра «бумага/зелёный/лайм», пара Fraunces + Manrope, все компоненты (чипы ингредиентов, карточки рецептов, кольца матча, модалки, тосты), адаптив (3 брейкпоинта), `prefers-reduced-motion`.
- **Страницы**: Home (hero, marquee, featured), Kitchen (пикер + живой матчинг + фильтры + быстрый выбор), Catalog (поиск/фильтры/избранное), Recipe (шаги, КБЖУ-бары, «в дневник»), Diary (фото-дневник с загрузкой), Community (лента готовок), Auth/Forgot/Reset.
- **Локализация EN/РУ/ҚАЗ**: контекст i18n, переключатель, автодетект языка, локализация единиц и фраз.
- **Микро-interactions**: scroll-reveal, анимация выбора чипа, hover-подъём карточек, count-up статистики.
- Исправления по фидбеку: перенос категорий в пикере, гонка синхронизации кладовой, объединение быстрого выбора.

### Адилет — Database (schema.sql, seed.js, routes/recipes.js)
- **Схема** = ER-модель из Assignment 3 (users, ingredients, recipes, recipe_ingredients, user_ingredients, instruction_blocks, photo_diary) + расширения: `is_staple`, КБЖУ-колонки, `tags`, `title_ru/kk`, `description_ru/kk` в шагах.
- **SQL-матчинг** (CTE `req`/`got`): обязательные = необязательные ≠ базовые (соль/масло/сахар/масло считаются всегда есть); `missing = total − have`; гарантия пересечения `have ≥ 1`; адаптивный порог «почти готово» при малом выборе.
- **Целостность**: FOREIGN KEY с CASCADE, UNIQUE email, UNIQUE (recipe_id, step_number), параметризованные запросы.
- **Аудит покрытия**: анализ «ингредиент → число рецептов», по которому закрыты пробелы (бекон, кукуруза) — основа индивидуального исследования.

### Санжар — Backend (server/, routes/)
- **Express API**: /api/ingredients, /api/recipes (+matching), /api/recipes/meta, /api/auth/*, /api/pantry, /api/diary (+/feed).
- **Аутентификация**: scrypt-хэши, HMAC-подписанные httpOnly-куки, гостевые аккаунты с апгрейдом при регистрации, одноразовые токены сброса пароля.
- **Безопасность**: helmet, rate-limit на auth/загрузки, валидация входа, лимит размера фото, upload через даунскейл в браузере.
- **Контент**: 68 рецептов (5 кухонь) с КБЖУ, шагами на 3 языках, тегами; 51 ингредиент; наборы быстрого выбора.
