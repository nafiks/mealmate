## Что реализовано (полный список)

- **Ядро**: пикер ингредиентов (51 шт., поиск по всем категориям, быстрые наборы
  «+» с маппингом ключей в id), живой матчинг (SQL CTE req/got, missing = total−have,
  have≥1 гарантия релевантности, адаптивный порог «почти готово» при ≤2 выбранных),
  два списка результатов, карточки с кольцами матча и «+ missing» чипами.
- **Рецепты**: 68 (KZ 14, EU 21, RU 13, AS 10, MX 10), КБЖУ, детальные шаги на
  EN/RU/KK (instruction_blocks.description_ru/kk), фото Unsplash (проверены контакт-
  листами, fallback — градиент+эмодзи), теги, фильтры (время/тег/кухня/поиск, поиск
  ищет и по локализованным названиям), избранное (localStorage).
- **Аккаунты**: scrypt + HMAC-cookie сессии, гостевые строки с апгрейдом при
  регистрации (перенос кладовой), регистрация/логин/логаут, сброс пароля
  (одноразовый SHA-256 токен, 30 мин; демо без почты — токен показывается на экране).
- **Дневник + сообщество**: фото сжаты в браузере (canvas → JPEG ≤~3 МБ) в data-URL,
  лента /community (только зарегистрированных авторов), удаление своих.
- **Локализация**: EN/РУ/ҚАЗ, переключатель в хедере, автодетект, контент в
  локализованных колонках БД, единицы/фразы на клиенте (i18n.js).
- **Безопасность**: helmet, rate-limit (auth/диary), валидация, параметризованный SQL,
  дневник запрещён гостям на сервере (401 auth_required).
- **Документы**: README.md (запуск/деплой Railway+Vercel), docs/TEAM-ROLES.md,
  docs/DEFENSE.md (шпаргалка к защите), docs/assignment4-report-draft.md +
  docs/Assignment4-Arsen-coverage-data.xlsx (реальные данные покрытия из БД).

## Известные особенности / последние правки

1. Быстрый выбор: наборы хранят ключи ингредиентов; /api/ingredients возвращает
   `key` (join по name с seed), клиент маппит в id, добавляет (не заменяет).
2. Матчинг: `maxAlmost = ids.length <= 2 ? 99 : 2` — при малом выборе показываем все
   релевантные (have≥1 уже гарантирует пересечение).
3. Гонка pantry: boot-синхронизация не затирает выбор, если pantryDirtyRef=true.
4. Категории пикера flex-wrap (не скролл) — фикс «не помещаются на ПК».
5. База пересоздавалась несколько раз — аккаунты из тестов удалены; тестовый юзер
   arsen2@mealmate.kz / student2026 может не существовать (пересоздать через UI).
6. Фото помечены как «проверенные просмотром», но часть — «близкие по духу»
   (shorpa = рагу в казане и т.п.); юзер просил точечную замену при замечаниях.
7. Временные файлы в корне workspace (_*.py, _source_docs) — мусор, можно удалить.
