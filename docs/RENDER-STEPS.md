# RENDER-STEPS — постоянная ссылка БЕЗ Railway (бесплатно, 10 минут)

> Репозиторий уже на GitHub: https://github.com/nafiks/mealmate
> Render — бесплатный хостинг: вход через GitHub, номер телефона не нужен.

## Что ты делаешь (5 кликов)

1. Открой **https://dashboard.render.com** → кнопка **Get Started** / **Sign in with
   GitHub** → нажми **Authorize** (ты уже залогинен в GitHub).
2. Справа вверху **New +** → выбери **Blueprint**.
3. В списке репозиториев выбери **nafiks/mealmate** → нажми **Connect**.
   (Если репозитория нет в списке — нажми Configure, отметь его галочкой, Save.)
4. Render прочитает файл `render.yaml` из проекта и покажет, что создаст сервис
   **mealmate** → нажми **Apply** / **Create Services**.
5. Подожди 5–7 минут, пока идёт сборка (статус Live внизу страницы).
6. Вверху страницы будет адрес вида
   `https://mealmate-xxxx.onrender.com` — **это твоя постоянная ссылка**.

## Честные ограничения бесплатного тарифа Render

| Ограничение | Что это значит |
|---|---|
| Засыпает после 15 минут без посетителей | Первый открывший ждёт ~50 секунд, дальше быстро |
| Файловая система сбрасывается при перезапуске | Рецепты восстанавливаются автоматически (сид), но **записи дневника и кладовая пользователей стираются** при рестарте/обновлении |
| 750 часов в месяц | Одного сайта хватает с запасом |

Вывод: для демонстрации и сдачи — идеально. Для «реального продукта с данными
пользователей» позже: Railway с диском ($5/мес) или Render с платным диском.

## Сравнение вариантов ссылки

| Вариант | Ссылка постоянная | Данные сохраняются | Нужен включённый ПК |
|---|---|---|---|
| localhost:3001 (start-site.bat) | только у тебя | да | да |
| Туннель (share-link.bat) | да, но меняется | да | да |
| **Render (эта инструкция)** | **да** | рецепты да, дневник сбрасывается | **нет** |
| Railway (docs/DEPLOY-STEPS.md) | да | да полностью | нет |

## Обновление сайта после правок

Двойной клик по `update-github.bat` в папке проекта (опиши изменение) — Render сам
пересоберёт сайт за 2–3 минуты.
