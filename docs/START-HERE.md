# START-HERE — как запустить MealMate и дать ссылку (для новичка, по шагам)

> Выполняй шаги по порядку. Команды, которые нужно набирать, отмечены так:
> `команда`. Их нужно набирать в чёрном окне (PowerShell) — как его открыть,
> написано в Шаге 3.

---

## ЧАСТЬ 1. Установить Node.js (один раз, 5 минут)

1. Открой браузер, зайди на **https://nodejs.org**
2. Нажми большую зелёную кнопку скачивания **LTS** (слева). Скачается файл вида
   `node-v24.x.x-x64.msi`.
3. Открой скачанный файл → Далее → Далее → Install (ничего не меняй) → Finish.
4. **Закрой все открытые окна терминала**, если были открыты (это важно — они не
   видят новую программу).
5. Проверка: открой PowerShell (как в Шаге 3) и набери `node -v` → должно показать
   версию, например `v24.10.0`. Если показывает — готово.

## ЧАСТЬ 2. Перенести проект в нормальную папку (5 минут)

Проект сейчас лежит в служебной папке ZCode. Перенеси его в удобное место.

1. Открой Проводник и зайди в:
   `C:\Users\arsen\.zcode\workspace\draft-eb8c8b71-fc6d-4309-a822-57fc59674b2f\`
2. Скопируй папку **mealmate** целиком (правый клик → Копировать) и вставь в
   `C:\Users\arsen\Projects\` (папку Projects создай, если нет).
3. Также скопируй файл **cloudflared.exe** из той же draft-папки внутрь
   `C:\Users\arsen\Projects\mealmate\` (он понадобится в Части 4).
4. Итог: у тебя есть `C:\Users\arsen\Projects\mealmate` со всем проектом.

## ЧАСТЬ 3. Запустить сайт у себя (10 минут)

1. Открой папку `C:\Users\arsen\Projects\mealmate` в Проводнике.
2. Кликни в адресную строку сверху, сотри путь, напиши `powershell` и нажми Enter —
   откроется синее/чёрное окно прямо в этой папке. (Это и есть «терминал».)
3. Набери команду и нажми Enter (установит библиотеки, ~1–2 минуты, один раз):
   ```
   npm install
   ```
4. Собери и запусти сайт:
   ```
   npm run build
   npm start
   ```
5. Появится строка `MealMate API on http://localhost:3001`. Открой в браузере
   **http://localhost:3001** — сайт работает.
6. Чтобы **остановить** сайт — в том же окне нажми Ctrl+C.
   Чтобы **запустить снова** (после перезагрузки ПК) — повтори шаги 2 и 4.

## ЧАСТЬ 4. Дать ссылку друзьям прямо сейчас (туннель, 2 минуты)

Ссылка будет работать, **пока запущен сайт (Часть 3) и открыто окно туннеля**.

1. Сайт запущен (Часть 3, шаг 4). Открой ВТОРОЕ окно PowerShell в той же папке
   (адресная строка → `powershell` → Enter).
2. Набери:
   ```
   .\cloudflared.exe tunnel --url http://localhost:3001
   ```
3. Через несколько секунд в тексте появится строка вида:
   `https://что-то-какое-то.trycloudflare.com` — **это и есть ссылка**. Скопируй её
   и отправь кому угодно.
4. Нюансы: при каждом запуске ссылка новая; работает, пока оба окна открыты и ПК
   включён; первое открытие ссылки может занять ~10 секунд.

## ЧАСТЬ 5. Что такое Railway и зачем (прочитай)

Railway — это **арендованный компьютер в интернете** (хостинг). «Деплой» — просто
слово для «скопировать проект на этот компьютер и запустить там».

Зачем: твой ПК выключается, спит, уезжает — и туннель умирает. После деплоя сайт
живёт на сервере Railway 24/7, у него постоянная ссылка, и твой ПК может быть
выключен. Это то, что значит «сайт работает автономно».

Стоимость: при регистрации Railway даёт стартовый бонус (~$5) — для учебного проекта
с такой нагрузкой его хватает надолго. Дальше тариф ~$5/мес, если захочешь держать
сайт включённым постоянно.

## ЧАСТЬ 6. Деплой на Railway (30 минут, делается один раз)

Сайт будет обновляться с GitHub: изменил файлы → залил на GitHub → Railway сам
пересобирает сайт. Поэтому сначала GitHub.

### Шаг 1. Залить проект на GitHub (10 минут)

1. Зарегистрируйся на **github.com** (если нет аккаунта).
2. Нажми «+» справа вверху → **New repository** → имя `mealmate` → Public → Create.
3. На открывшейся странице нажми ссылку **uploading an existing file**.
4. В Проводнике зайди в `C:\Users\arsen\Projects\mealmate`, **удали в копии папку
   `node_modules` и папку `client\dist`** (они гигантские и не нужны — Railway
   создаст их сам; это не сломает проект у тебя на ПК). Теперь выдели всё остальное
   (папки client, server, docs, файлы package.json, vite.config.js, README.md,
   .gitignore и т.д.) и **перетащи в окно браузера**.
5. Дождись загрузки (папок много — может быть 5–10 минут), внизу нажми
   **Commit changes**.

### Шаг 2. Задеплоить на Railway (10 минут)

1. Зайди на **railway.app** → **Login with GitHub** → разреши доступ.
2. **New Project** → **Deploy from GitHub repo** → выбери `mealmate`.
3. Дождись первой сборки (5–7 минут; может упасть — тогда Settings → Source и
   убедись, что выбран твой репозиторий, и нажми Retry).
4. **Подключи постоянный диск для базы данных** (иначе рецепты сбрасываются при
   каждом перезапуске): в проекте открой твой сервис → вкладка **Variables** →
   добавь переменную `MEALMATE_DB` = `/data/mealmate.db` → вкладка **Settings** →
   раздел **Volumes** → **+ New Volume** → Mount path: `/data` → Add.
5. **Получи ссылку**: Settings → раздел **Networking** → **Generate Domain** →
   Railway выдаст адрес вида `mealmate-production-xxxx.up.railway.app`.
6. Открой этот адрес — сайт работает. Эта ссылка теперь постоянная: ПК выключен,
   сайты нет на твоём компе — ссылка работает.

### Шаг 3. Обновлять сайт после правок

Изменил что-то локально → на GitHub в своём репозитории нажми **Add file → Upload
files** → перетащи изменённые файлы (с заменой) → Commit. Railway заметит и сам
пересоберёт сайт за пару минут.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `node -v` пишет «не является командой» | Переустанови Node по Части 1 и ПЕРЕЗАПУСТИ окно PowerShell |
| `npm install` сыплет ошибки | Проверь, что ты в папке mealmate (должен быть файл package.json) |
| Сайт открывается, но без стилей/картинок | Сначала `npm run build`, потом `npm start` |
| Ссылка туннеля не открывается у друга | Проверь, что оба окна (сайт и туннель) запущены и ПК не спит |
| Railway выдаёт ошибку сборки | Открой лог деплоя (Deployments → View Logs) — обычно не хватает файлов: проверь, что на GitHub есть папки client и server |
| Рецепты пропали после перезапуска на Railway | Не подключён Volume (Шаг 2.4) |
